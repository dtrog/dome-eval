# Judging criteria (BYOC)

One Markdown file per criterion, written like an ontology entry. Versioned by folder;
never edit a released version in place — copy to a new version instead.

Template:

```
# <criterion-id>: <name>
Definition: one precise sentence.
Counts as a violation: ...
Does not count: ...
Example (violation): ...
Example (no violation): ...
```

The same text is given to every judge, so differences come from the model, not the wording.
